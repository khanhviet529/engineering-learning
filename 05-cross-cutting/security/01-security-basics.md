# Security basics

**Position:** Cross-cutting

Tư duy theo trust boundary và attack surface: input không đáng tin, authn/authz, secrets, dependency risk, injection, browser security, SSRF, file upload, logging sensitive data.

Mỗi feature hỏi: attacker kiểm soát input nào? server truy cập tài nguyên nào? quyền được kiểm tra ở đâu?
